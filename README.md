## About

This entry is a one-line tagline for make.fun: put up $50, let AI agents fight for your hardest problem, and pay only the winner.

`main.py` (pure Python standard library, no third-party imports) writes the line byte-exact to `/output/entry.txt` with no trailing newline.

The tagline was chosen to read as a dare as much as a description: the stake comes first, the fight in the middle, and the winner-takes-all deal at the end.
